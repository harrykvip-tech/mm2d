  • ◀ ရက်စွဲ ▶ ယနေ့ နဲ့ ရက်ရွေးပါ။ ယနေ့မဟုတ်တဲ့ ရက်ကိုကြည့်နေရင် အနီရောင်နဲ့ သတိပေးပါတယ်။
  • + နာမည် ကိုနှိပ်ပြီး ဖောက်သည်နာမည် ထည့်ပါ။ နာမည်အရေအတွက် ကန့်သတ်မရှိပါ။ နာမည်ကိုနှိပ်ရင် အဲဒီသူ့စာရင်းကို ဖွင့်ပါတယ်။ အားလုံး ကတော့ လူအားလုံးရဲ့ စုစုပေါင်းပါ။

  • တစ်ကြောင်းချင်း အမြန်ထည့်ချင်ရင် အောက်တန်းမှာ ဂဏန်း၊ ငွေ ရေးပြီး + (သို့ Enter) နှိပ်ပါ။ R ခလုတ်ကို နှိပ်ထားရင် ပြောင်းပြန်ပါပါတယ်။

၄။ နားမလည်တဲ့ စာကြောင်း
  • နားမလည်တဲ့ စာကြောင်းရှိရင် အနီရောင်နဲ့ အဲဒီစာကြောင်းကို ပြပါတယ်။ ဘာမှ မထည့်သေးပါဘူး။ စာကို ပြင်ပြီး ပြန်နှိပ်ပါ။
  • နားမလည်တာကို ကျော်ပြီး ကျန်တာ ထည့်မည် ကိုနှိပ်ရင် နားမလည်တဲ့ စာကြောင်းတွေကို ကျော်ပြီး မှန်တဲ့ စာကြောင်းတွေကိုပဲ ထည့်ပါတယ်။
  • ဖောက်သည်ရဲ့ နာမည်၊ နှုတ်ဆက်စာတွေ ပါလာရင် အဲဒီစာကြောင်းက ကျော်သွားပါမယ်။ ငွေမပါတဲ့ ဂဏန်းလည်း ကျော်သွားပါမယ်။
၅။ ထွက်ဂဏန်း တွက်နည်း
  • "ထွက်ဂဏန်း တွက်ရန်" မှာ ထွက်ဂဏန်း ၂ လုံး၊ နုတ် (%)၊ ဆပေး (×) ထည့်ပါ။ ဖောက်သည်တစ်ယောက်ချင်းအတွက် % နဲ့ ဆပေးနှုန်း သီးသန့်လည်း ပေးလို့ရပါတယ် (နာမည်ရွေးပြီး ခေါင်းစဉ်အောက်က ကွက်၊ အလွတ်ထားရင် ပုံမှန်နှုန်းကို သုံးပါမယ်)။
  • ပေါ်လာတာတွေ: စုစုပေါင်း ထိုးကြေး၊ % နုတ်ငွေ၊ နုတ်ပြီး ကျန်ငွေ၊ ထွက်ဂဏန်းပေါ် တင်ထားငွေ၊ ဆပေးရမည့်ငွေ၊ အမြတ်/အရှုံး = ကျန်ငွေ − ဆပေးငွေ
  • အားလုံး ကိုနှိပ်ရင် လူတစ်ယောက်ချင်းစီရဲ့ ဇယားနဲ့ စုစုပေါင်းကို တစ်ပြိုင်နက် ကြည့်လို့ရပါတယ်။
  • ★ က ငွေအများဆုံး တင်ထားတဲ့ ဂဏန်းပါ။ ငွေတူရင် တူတဲ့ဂဏန်းအားလုံး ★ ပါပါတယ်။ ဂဏန်းအသစ်ထည့်လို့ ပိုများသွားရင် အလိုအလျောက် ရွှေ့ပါတယ်။
၆။ ပြင်၊ ဖျက်
  • နာမည်ရွေးထားရင် အောက်က "စာရင်းများ" မှာ ထည့်ထားတဲ့ စာတစ်ခုချင်းစီ ဘေးက × နဲ့ ဖျက်လို့ရပါတယ်။
  • နာမည်ပြင်ချင်ရင် "ခေါင်းစဉ် (နာမည်)" ကွက်ထဲမှာ တိုက်ရိုက်ပြင်ပါ။ နာမည်ဖျက် ကို နှစ်ခါနှိပ်မှ ဖျက်ပါမယ် (အမှားမခံအောင်)။
၇။ တစ်နေ့တာ မှတ်တမ်း (History)
  • ဒီ Tab ထဲက "တစ်နေ့တာ မှတ်တမ်း" မှာ ရက်တိုင်းရဲ့ စုစုပေါင်း (12:01 နဲ့ 4:30 သီးသန့်စီ) ပြပါတယ်။ ထွက်ဂဏန်းထည့်ထားရင် အမြတ်/အရှုံးကိုလည်း ပြပါမယ်။
  • ကွက်ကိုနှိပ်ရင် အဲဒီနေ့ အဲဒီအချိန်စာရင်း ပွင့်ပါတယ်။
  • ရက်သစ်ဖွင့်ရင် ဖောက်သည်နာမည်၊ %၊ ဆပေးနှုန်းတွေ မနေ့ကအတိုင်း ပါလာပြီး ဂဏန်းတွေပဲ ရှင်းနေပါမယ်။
၈။ Key / အသုံးပြုခွင့်
  • App ကို ပထမဆုံးဖွင့်ရင် Device ID ပေါ်ပါမယ်။ Copy နှိပ်ပြီး Telegram ကနေ Developer ကို ပို့ကာ Activation key ဝယ်ပါ။
  • ရလာတဲ့ key ကို "Activation key ထည့်ရန်" ကွက်မှာ paste လုပ်ပြီး Key ဖွင့်မည် နှိပ်ပါ။ key က ဒီ Device ID စက်မှာပဲ သုံးလို့ရပါတယ်။
  • သက်တမ်းကုန်ခါနီးရင် ဒီ Tab ထဲက Key သက်တမ်းတိုးရန် ခလုတ်ကို နှိပ်ပြီး Telegram နဲ့ ဆက်သွယ်ပါ။ key အသစ်ရရင် ထပ်ထည့်ပါ။
၉။ စာရင်းကူးပို့၊ ထိတဲ့သူများ
  • "ထွက်ဂဏန်း တွက်ရန်" အောက်က 📋 စာရင်းကူးမည် ကိုနှိပ်ရင် ရွေးထားတဲ့ နာမည်ရဲ့ စာရင်းကို စာအဖြစ် ကူးပေးပါတယ်။ Telegram/Viber မှာ paste လုပ်ပြီး ဖောက်သည်ကို ပို့ပါ။ ↗ ပို့မည် ကနေ တိုက်ရိုက်လည်း ပို့လို့ရပါတယ် (ဖုန်းက ခွင့်ပြုရင်)။
  • စာထဲမှာ ငွေတူတဲ့ ဂဏန်းတွေကို စုပေါင်းပြပါတယ်။ "% နုတ်ပြီး ကျန်ငွေပါ ထည့်မည်" ကွက်ကို ဖြုတ်ရင် နုတ်ငွေ၊ ကျန်ငွေကို မထည့်ပါဘူး။
  • အားလုံး ကိုရွေးပြီး နှိပ်ရင် လူတိုင်းရဲ့ စုစုပေါင်းချုပ်ကို ကူးပေးပါတယ်။
  • ထွက်ဂဏန်းထည့်ထားရင် အားလုံး မှာ "ထိတဲ့သူများ" ဇယားပေါ်ပါမယ် (ဘယ်သူ၊ တင်ငွေ၊ ဆပေးရမည့်ငွေ၊ စုစုပေါင်း)။ နာမည်တစ်ခုရွေးထားရင် ထိ/မထိ ပြပါတယ်။
၁၀။ Backup / Restore
  • စာရင်းတွေက ဖုန်းထဲမှာပဲ ရှိတာမို့ Backup ပုံမှန်လုပ်ထားပါ။ Tab ထဲက "Backup / Restore" မှာ:
  • Backup ဖိုင် ထုတ်မည်: ဖိုင်တစ်ခု (2d-backup-ရက်စွဲ.json) ဒေါင်းလုဒ်ဖြစ်ပါတယ်။ ဖိုင်ကို Telegram Saved Messages/Drive ထဲ သိမ်းထားပါ။
  • Backup စာ ကူးမည်: ဖိုင်မရတဲ့အခါ (APK မှာ) စာအဖြစ်ကူးပြီး Telegram "Saved Messages" ထဲ paste လုပ်သိမ်းပါ။
  • ပြန်သွင်းမည်: ဖိုင်ရွေးပါ (သို့) စာ paste လုပ်ပါ။ ပြီးရင် ခလုတ်ကို နှစ်ခါနှိပ်ပါ။ Backup ထဲက ရက်တွေက ဒီဖုန်းက အဲဒီရက်တွေကို အစားထိုးပါမယ်၊ Backup ထဲမပါတဲ့ ရက်တွေကို မထိပါ။
  • Backup မလုပ်တာ ၇ ရက်ကျော်ရင် (သို့) တစ်ခါမှ မလုပ်ရသေးရင် စာမျက်နှာထိပ်မှာ အဝါရောင်သတိပေးပါမယ်။ နှိပ်ရင် Tab ပွင့်ပါတယ်။
  • Activation key က Backup ထဲမပါပါဘူး။ ဖုန်းအသစ်ဆိုရင် Device ID အသစ်နဲ့ key ထပ်ယူရပါမယ်။
၁၁။ သတိပြုရန်
  • စာရင်းအားလုံးကို ဒီဖုန်းရဲ့ browser/app ထဲမှာပဲ သိမ်းပါတယ်။ Browser data ရှင်းရင်၊ app ကို ဖျက်ရင် စာရင်းပျောက်ပါမယ်။ Device ID လည်း ပြောင်းသွားပါမယ်။ ဒါကြောင့် Backup လုပ်ထားပါ။
  • ထွက်ဂဏန်းရလဒ်ကို app က အလိုအလျောက် မယူပါ။ ကိုယ်တိုင် ထည့်ပေးရပါမယ်။
